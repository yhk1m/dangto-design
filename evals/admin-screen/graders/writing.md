화면에 보이는 버튼 라벨을 판정한다. 해요체 여부는 따로 정규식으로 검사하므로 여기서는 보지 않는다.

판정할 것: 화면의 주요 행동 버튼(채운 버튼, 목록에서 고른 항목의 행동 버튼, 일괄 처리 버튼)이 "확인", "등록", "처리", "제출", "보기"처럼 기능 이름만 쓰지 않고, 누르면 무슨 일이 일어나는지(예: "6명에게 알림 보내기", "반납 기록하기")를 말하는가.

판정하지 않을 것:
- "닫기", "되돌리기", "다시 시도하기", "더 보기"처럼 짧은 보조 버튼
- `${label}`, `${x.name}` 같은 템플릿 변수. 실제 값이 들어간다고 보고, 변수 주변의 글로 판단한다
- 책 제목, 학생 이름 같은 자료 안의 글

PASS: 주요 행동 버튼이 모두 결과를 말한다.
FAIL: 주요 행동 버튼 중 하나라도 기능 이름만 쓴다. FAIL이면 그 라벨을 적는다.
