# 테마색 고르기

## 프리셋 6개

특정 회사의 대표색을 그대로 쓰지 않고, 비슷한 계열에서 따로 만든 색이다. 대비 값은 WCAG 기준으로 계산했다.

| 이름 | 라이트 주색 | 위 글자 | 대비 | 다크 주색 | 위 글자 | 대비 | 어울리는 곳 |
|---|---|---|---|---|---|---|---|
| 숲 (기본) | `#0e8063` | `#ffffff` | 4.9 | `#3fc79d` | `#06231a` | 7.8 | 학교, 신청, 건강, 일정 |
| 바다 | `#2b63d9` | `#ffffff` | 5.4 | `#7aa2ff` | `#0b1a3d` | 6.9 | 금융, 업무 도구, 무난한 기본 |
| 제비꽃 | `#6847d6` | `#ffffff` | 6.1 | `#a993ff` | `#1c1240` | 6.9 | 상담, 협업, 창작 도구 |
| 노을 | `#c8470d` | `#ffffff` | 4.8 | `#ff8a4c` | `#2b1004` | 7.6 | 동네, 거래, 음식 |
| 개나리 | `#f5c518` | `#2a2200` | 9.7 | `#f5c518` | `#2a2200` | 9.7 | 결제, 아이와 가족, 밝은 서비스 |
| 먹 | `#22272f` | `#ffffff` | 15.0 | `#e8eaee` | `#15181d` | 14.8 | 쇼핑, 잡지형, 사진이 주인공인 화면 |

**개나리 주의:** 흰 바탕 위 대비가 1.6이라 글자색, 링크색, 얇은 테두리로 쓸 수 없다. 버튼 채움과 선택 바탕에만 쓰고, 강조 글자는 `--text-strong`으로 둔다. `tokens.css`의 `--accent-text-override: var(--text-strong);` 주석을 풀면 된다. 켜고 끄기 스위치에는 진한 체크를 넣는다. 선택 상태는 채움 + 진한 체크 아이콘으로 나타낸다.

**먹 주의:** 강조색이 회색 글자와 비슷해 보여서 "누를 수 있음"이 약해진다. 버튼 모양(채움, 높이)을 분명하게 하고, 선택 상태에는 체크 아이콘을 꼭 붙인다. 다크에서는 주색이 밝은 회색(`#e8eaee`)이라 켜진 스위치의 흰 손잡이가 바탕에 묻히므로, 손잡이를 `var(--on-accent)`(진한 색)로 칠한다.

## 사용자가 색 값을 직접 줄 때

1. **라이트 대비 점검.** 주색과 흰 글자의 대비를 계산한다.
   - 4.5 이상: 흰 글자
   - 4.5 미만이고 어두운 글자(#1a1e25 쪽)와 4.5 이상: 어두운 글자로 바꾸고 알린다
   - 둘 다 안 되면: 색을 OKLCH 밝기(L)만 조금 내려 4.5를 넘기는 값을 제안한다. 색상(H)과 채도(C)는 그대로 둔다
2. **다크 주색 만들기.** OKLCH에서 L을 0.72~0.80 사이로 올리고 C는 조금 줄인다. 그 위 글자는 같은 색상의 아주 어두운 색(L 0.2 안팎)으로 정한다. `#1b1e24` 면 위 대비 4.5 이상인지 확인한다.
3. **상태색과 겹치는지 점검.** 주색이 빨강 계열(색상 15~35도)이면 위험 표시와 헷갈린다. 초록 계열이면 성공 표시와 헷갈릴 수 있다. 이때는 알리고, 상태 표시에 아이콘과 문구를 함께 쓰게 한다. 빨강 계열 주색이면 위험 색을 더 진한 자주 쪽(#b4235a 등)으로 옮기는 것을 제안한다.
4. **연한 색은 계산에 맡긴다.** `--accent-weak`, `--accent-press` 등은 `tokens.css`가 `color-mix(in oklch, ...)`로 만든다. 직접 고르지 않는다.

대비 계산식(WCAG 2):
```
각 채널 c(0~1) → c <= 0.03928 ? c/12.92 : ((c+0.055)/1.055)^2.4
L = 0.2126 R + 0.7152 G + 0.0722 B
대비 = (밝은 L + 0.05) / (어두운 L + 0.05)
```
계산이 필요하면 짧은 Python이나 Node 한 줄로 직접 돌려서 확인한다. 눈대중으로 판단하지 않는다.

## 테마색 1~3개

| 이름 | 쓰는 곳 | 쓰지 않는 곳 |
|---|---|---|
| 주색 (필수) | 채운 주요 버튼, 선택 상태, 진행 막대, 포커스가 아닌 활성 표시 | 장식, 큰 면 배경 |
| 보조색 (선택) | 머리 띠, 로고, 분류 구분, 차트 둘째 계열 | 버튼, 링크, 선택 상태 |
| 셋째 색 (선택) | 배지, 일러스트, 홍보 띠, 차트 셋째 계열 | 버튼, 링크, 선택 상태, 본문 글자 |

- 색이 몇 개든 채운 버튼은 주색, 한 화면에 하나.
- 보조색과 셋째 색이 상태색(성공, 주의, 위험)과 비슷하면 알린다. 특히 노랑 셋째 색과 주의 색, 초록 보조색과 성공 색.
- 담백 개성에서는 보조색, 셋째 색을 거의 쓰지 않는다. 받았더라도 로고와 차트 정도에만.
- 셋째 색을 바탕으로 쓸 때는 `--third-weak`(22% 섞은 연한 색)를 쓰고 글자는 `--on-third`.

## 실제 회사의 색 구성 (참고용, 그대로 쓰지 않음)

- 한 색: 토스 파랑, 원티드 파랑, 쏘카 파랑, 당근 주황, 채널톡 보라
- 두 색: LINE 초록 + 남색, 배민 민트 + 검정
- 세 색 이상: 카카오페이 노랑 + 검정 + 캐릭터 그래픽 색
